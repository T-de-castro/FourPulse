# FourPulse -> Nome do Grupo (Nome do Software não definido)

Sistema de Controle de Chamados com foco na Defesa CIvil

O projeto se baseia em um sistema de Controle de Chamados para uso exclusivo da Defesa Civil, o mesmo será personalizado e adaptado para uso dos mesmos. 
O sistema será Web, com a seguinte arquitetura prevista:
- Backend: Python;
- Frontend: Python (Streamlit);
- Banco de Dados: PostgreSQL;
- Visualização dos dados: Power BI;

A ideia é realizar um sistema simples, que contenha as funcionalidades de:
- Cadastro de usuários;
- Cadastrar novos chamados (Tanto pelo usuário interno quanto por usuário externo);
- Realizar o controle dos chamados existentes;
- Visualizar e apresentar os dados via Power BI Desktop (Arquivo gerado);

Dentre os módulos previstos temos:
- Cadastro de usuários;
- Login;
- Cadastro de Chamados;
- Operacional (Controle dos chamados);
